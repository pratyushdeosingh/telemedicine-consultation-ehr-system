# Telemedicine Consultation and EHR System - DA2

Team repository for the BACSE202 Database Systems Digital Assignment 2.

## Project structure

- `database/` - Oracle SQL schema, sample data, SQL queries, and PL/SQL programs
- `backend/` - Express REST API and Oracle database integration
- `frontend/` - React web application and API integration
- `docs/` - Setup notes, workflow diagrams, screenshots, and report material

## Branches

- `main` - reviewed and integrated code
- `database` - Member 1 database implementation
- `backend` - Member 2 backend and API implementation
- `frontend` - Member 3 frontend implementation

Work should be committed to the appropriate role branch and merged into `main` after testing.

## Local execution order

1. Run the database schema and sample-data scripts.
2. Run the PL/SQL object scripts.
3. Configure and start the backend API.
4. Configure and start the frontend application.

Never commit database passwords, `.env` files, or `node_modules`.
